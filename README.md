To run the bot, you will need the following components:

Python 3.8+ - Make sure you have Python version 3.8 or higher installed. You can download it from the official Python website.

FFmpeg - FFmpeg is required for audio and video processing.

Download FFmpeg from the official website.

Add FFmpeg to your system's PATH environment variable so that it can be called from the command line.

Virtual Audio Cable - The bot uses a virtual audio cable to route audio to Discord. One popular option is:

VB-Audio Cable: Download and install VB-Audio Cable. This free software creates a virtual audio device that will be used for audio playback.

After installation and restarting your computer, you will need to specify the name of the device (e.g., "Line 1 (Virtual Audio Cable)") in the bot's code.
